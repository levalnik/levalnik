## 🚀 Featured project

### 🩺 [MedSoft — Medical Information System](https://github.com/levalnik/MedSoft)

A team-built **.NET 10** web application for managing patients, electronic medical records, healthcare staff, and user accounts.

- **Architecture:** layered design, MediatR, FluentValidation, EF Core, and PostgreSQL.
- **Medical records:** versioned history stored in PostgreSQL JSONB, including state reconstruction at a selected point in time.
- **Security:** role-based permissions, TOTP two-factor authentication, JWT with RS256, refresh-token rotation, and Argon2id password hashing.
- **UI & quality:** Blazor WebAssembly, audit logs, xUnit, Testcontainers, and Playwright.

**Stack:** `C#` `ASP.NET Core` `.NET 10` `Blazor WebAssembly` `PostgreSQL` `EF Core` `Docker`
